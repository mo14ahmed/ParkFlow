COE/ELE 70AB Capstone Project

Automatic Parking Lot Gate Closure and Smart Space Monitoring System

A parking system that watches every space with a camera, closes the gate automatically when the lot is full, and shows drivers live availability on the web and on their phone.

Read milestone report I

About the project

Finding a parking spot usually means circling a lot that is already full. Our system removes that guesswork. A fixed camera and computer vision track which spaces are taken, the entrance gate only opens when a space is free and the driver is authorized, and every change is sent to a central server so drivers can check availability before they arrive.

The first parking building is built as a physical model, and additional buildings are simulated to show that the design scales to many locations. Every building reports to one central cloud server running on our VPS, which also hosts this website and the API used by the iOS and desktop apps.

Detect

A camera with YOLO vehicle detection marks each mapped space as free or occupied.

Decide

A local gateway runs the gate logic, opening for authorized entries and staying closed when the lot is full.

Display

LEDs, the entrance sign, the website and the iOS app all show the same live availability.

System modules
